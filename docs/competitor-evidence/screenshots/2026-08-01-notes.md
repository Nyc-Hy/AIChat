### Composer 状态

- placeholder: `随心输入`
- 左下红色 badge: `完全访问` (Full access / `danger-full-access`)
- 右下: `5.6 Sol 极高` (model) + 🎤 (voice) + ⬆️ (send)
- 左下 `+` 按钮 (附件)

**关键发现**：Composer 显示的权限是 `完全访问` 单 badge，**不是** plan §4 "Read only / Workspace / Full access" 3 档中选一个。Codex 的实际模型是 **2 个独立 toggle**：
- `默认权限` (Default permissions / `on-request`)
- `完全访问权限` (Full access / `danger-full-access`)

两个 toggle 各自独立打开/关闭，组合出 4 种状态。**plan §7 Wave 4 的 "3 档 profile" 写法要改**。
